# Related evidence and future comparisons

The Observatory does not claim priority over applying moral or value
instruments to language models. Relevant external work includes:

- Moral Foundations and other value instruments applied to LLMs;
- comparisons between questionnaire responses and concrete moral judgments;
- cross-cultural and multilingual evaluation;
- public value-evaluation platforms and consumer-facing model comparison
  tools;
- version- and checkpoint-specific behavioural evaluation;
- critiques of psychometric validity and prompt sensitivity in LLMs.

## How external evidence will be used

Future web blocks should classify each source as one of:

- direct replication;
- harmonized comparison;
- conceptual convergence;
- methodological support;
- qualification;
- conflicting evidence;
- comparison pending.

No external tool should be described as replicating an Observatory result until
instrument, scoring, prompt, configuration and human-reference equivalence have
been checked.

Detailed comparisons, including candidate comparisons with public model-value
quizzes and dashboards, are intentionally deferred from version 0.3.
