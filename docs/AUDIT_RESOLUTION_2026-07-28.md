# Resolution of the 28 July 2026 technical audit

## Resolved

- Repeated generations are not used as independent task units.
- Ola 2 item counts are corrected to 16 proportionality, four equality and 20
  contrast items.
- SciPy is declared as a dependency.
- GPT modes are separated.
- DeepSeek Chat is excluded from derived results; Reasoner is independent.
- The original mismatched language comparison is removed and replaced by a
  matched `lente_A` analysis.
- “Human range” and `intervals_overlap` language are removed from generated
  outputs.
- DSE coefficients report vignette-set counts and use 5,000 bootstrap
  replicates.
- Temperature-zero claims are removed.
- The historical version threshold is marked as adopted during reanalysis, not
  preregistered.
- The DSE fixed-amount and reconstructed-instrument limitations are restored.
- Citation licensing is corrected to CC BY-SA 4.0 for the dataset and
  documentation, with code separately MIT.
- Tests now verify every manifest entry and the new classification rules.

## Still open by design

- Human microdata and equivalent human uncertainty.
- A validated representation or disagreement-compression metric.
- MFQ collection-code and reference provenance.
- Verification of original DSE materials.
- Independent human methodological review.
- Purpose-built language and longitudinal studies.
- Harmonized comparison with external papers and tools.

These open items do not block construction of a first web version provided the
web follows `docs/WEB_CONTENT_MAP.md` and does not convert them into claims.
