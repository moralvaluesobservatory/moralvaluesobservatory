# Main findings available for the web

Only the following statements should appear as active empirical findings.

## Finding 1 — task-dependent allocation criteria

In the reconstructed DSE vignette bank, every tested configuration allocated
more to high-performance and high-dedication recipients in the workplace task,
and more to recipients with tight finances in the inheritance task.

Use the coefficients and intervals in
`data/results/active/dse_coefficients.csv`.

## Finding 2 — equal splits relative to published aggregate estimates

For both tasks, the model bootstrap intervals for exact equal splits were below
all selected published human aggregate point estimates included in the
comparison.

Required qualification:

> The human side consists of aggregate point estimates from different samples
> and subgroups. Equivalent human uncertainty and individual-level distributions
> are not available.

Use `data/results/active/dse_reported_reference_position.csv`.

## Methodological finding — repeated generations

Repeated generations are not independent people or independent task items.
Intervals resample whole vignette sets or items. Generation rows and task
clusters must always be reported separately.

## Not active findings

MFQ profiles, country similarities, language comparisons, stated-versus-chosen
patterns and historical version comparisons belong to `Evidence to date` or
the research record, not this page's main findings.
